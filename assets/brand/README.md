# Natsu brand assets

Source files and pipeline for the Natsu icon. The brand story, design rationale and palette are in
[docs/brand.md](../../docs/brand.md).

Every file here is generated by [`tools/natsu_icon.py`](tools/natsu_icon.py), so change the generator
and rebuild rather than editing the SVGs by hand.

## SVG sources

| File | What it is | Used for |
|---|---|---|
| `natsu-mark.svg` | **Master.** Full-colour mark on a transparent background (layout seed 12) | Windows and Linux app icons, in-app logo, splash |
| `natsu-mark-32.svg` | Small preset: fewer, larger petals and a bigger prompt | 30–50 px raster slots |
| `natsu-mark-24.svg` | Small preset, simpler again | 20–24 px slots |
| `natsu-mark-16.svg` | Smallest preset, `>` only (no cursor) | 16 px slot |
| `natsu-mark-mono.svg` | One colour (`currentColor`); petal outlines, floret eyes and `>_` are cut out | Tray / template images, Android themed icon, print |
| `natsu-mark-tonal.svg` | One colour (`currentColor`) with depth in the alpha channel: crown opaque, centre translucent, `>_` opaque | UIs that tint the mark (mobile) |
| `natsu-app-icon-macos.svg` | Mark on a white rounded-square plate on the Apple grid, with a soft shadow | `icon.icns` |
| `natsu-app-icon-square.svg` | Mark on a full-bleed white square | Mobile `icon.png` |

## Generated rasters

Run from the repository root:

```sh
python assets/brand/tools/build_assets.py
```

You need Python 3 with Pillow, plus the repo's `node_modules`: images are rasterised with
`npx tauri icon`, which uses resvg, the same renderer Tauri and GPUI use.

## Things to know

- **`AppIcon.icon/Assets/icon.png` is the menu-bar template, not the app icon.**
  `src-tauri/src/mono_chat.rs` and `crates/natsu-gpui/src/monos/status.rs` both read this file as a
  single-colour template image. It therefore stays a white mark with `>_` cut out. The Icon Composer layer
  is `Assets/natsu-mark.png`.
- **`src-tauri/macos/Assets.car` is compiled in CI, not here.** macOS 26 draws the app icon from this
  catalogue. [`scripts/compile-macos-icon.sh`](../../scripts/compile-macos-icon.sh) compiles it from
  `AppIcon.icon` with Xcode 26's `actool`, so no local Mac is needed:
  - Both macOS release jobs (`release.yml`, `native-release.yml`) run the script before packaging.
  - The macOS `check` job in `ci.yml` runs it with `--strict` and uploads the result as the
    `macos-assets-car` artifact.
  - The committed copy is the fallback a release ships if `actool` fails; the run then shows a warning.
    When `AppIcon.icon` changes, refresh it from that artifact
    (`gh run download <run-id> --repo ChenRuoT/natsu -n macos-assets-car -D src-tauri/macos`).
  - Older macOS versions use `icon.icns`.
- **Small in-app logos.** `public/natsu.png` and the GPUI `natsu.png` are 1024 px renders of the master.
  The desktop UI shows them at 16 px (update card, update notification), where the petals blur. If that
  matters, point those spots at a raster of `natsu-mark-16.svg` / `natsu-mark-32.svg`.
- **Mobile config.** `mobile/app.json` still sets `android.adaptiveIcon.backgroundColor` and the splash
  `backgroundColor` to `#000000`. Neither was changed here. Set the adaptive-icon colour to `#FFFFFF` to match
  the new white background image. The colour mark also works on the black splash.

## Changing the design

- **Layout, colours, prompt:** edit `MASTER` in `tools/natsu_icon.py`. Change `seed` to get a different
  petal arrangement.
- **Small sizes:** edit `PRESETS`.
- **Rebuild:** run `build_assets.py` and check the results at 16, 32 and 64 px on both light and dark backgrounds.

You can also render a single variant by itself:

```sh
python assets/brand/tools/natsu_icon.py color out.svg                 # master
python assets/brand/tools/natsu_icon.py mono out.svg fill=#FFFFFF     # white cut-out mark
python assets/brand/tools/natsu_icon.py color out.svg preset=small32 scale=0.8
```
